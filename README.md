# 💻 Dilemas Digitais

Projeto educacional sobre os principais dilemas encontrados no mundo digital.

O objetivo é incentivar o uso seguro, ético e consciente da tecnologia,
apresentando problemas comuns e possíveis soluções.

---

## 🎯 Objetivo

A tecnologia está cada vez mais presente na vida das pessoas.

Com isso, surgem diversos desafios relacionados à:

- Privacidade
- Fake News
- Cyberbullying
- Uso excessivo de tecnologia
- Inteligência Artificial
- Jogos digitais
- Segurança na internet
- Cidadania digital

O projeto apresenta esses dilemas de maneira simples e interativa.

---

## 🚀 Funcionalidades

### 📚 Dilemas

O usuário pode conhecer diferentes problemas relacionados ao mundo digital.

### 💡 Soluções

Cada dilema possui uma solução prática com recomendações para lidar
com a situação.

### 🔎 Filtros

É possível filtrar os dilemas por categoria:

- Segurança
- Social
- Tecnologia

### 🧠 Quiz

O projeto possui um quiz com 10 perguntas sobre segurança e cidadania digital.

Ao final, o usuário recebe sua pontuação.

### 🌙 Modo escuro

O site possui modo claro e modo escuro.

A preferência do usuário é salva no navegador utilizando `localStorage`.

### 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- Computadores
- Notebooks
- Tablets
- Celulares

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando:

- HTML5
